# youssefjalloul.com

Static, multi-page website for Youssef Jalloul. No framework, no database: plain HTML, CSS and a little JavaScript, generated by one Python script.

## What's in this folder

| Path | What it is |
|---|---|
| `dist/` | **The finished website.** Upload the contents of this folder to Hostinger (`public_html`). |
| `build.py` | Builds `dist/` from the content. Shared header, booking band and footer live here. |
| `content/pages/*.py` | One module per group of pages (home, inner pages, private AI). |
| `content/pages/_sec_*.html` | Reusable sections (cases, ventures, FAQ, etc.) that the pages assemble. |
| `content/insights/*.md` | Every article. Front matter (JSON) on top, Markdown below. |
| `covers.py` | The code-drawn illustrations (Toastie, Ding, Frosty and friends). |
| `make_og.py` | Renders the 1200x630 share cards into `static/assets/og/`. |
| `static/` | Copied as-is into `dist/`: CSS, JS, fonts, logos, images, `genome.json`, `llms.txt`, `robots.txt`. |
| `BRAND-VOICE.md` | The voice, cast, enemy and Generative Brand rules for anyone writing for the site. |
| `source/` | Originals: LinkedIn articles export, The Generative Brand deck. |
| `archive/` | Previous single-page version, kept just in case. |

## Rebuild after editing

```bash
pip install markdown playwright   # once
python3 make_og.py                # only if you added or renamed an article
python3 build.py                  # writes dist/
```

## Add an article

1. Copy any file in `content/insights/` and rename it to the new slug.
2. Edit the JSON front matter: `slug`, `title`, `description` (answer the question in one sentence), `date`, `art` (one of: toaster, microwave, fridge, trio, house, leak, brain, tablets, spiral, desert, magnifier, couch, agents, coins), `kicker`, `order` (higher shows first), `origin` (`site` or `linkedin`), optional `faq` list of `[question, answer]`.
3. Write the article in Markdown below the `---` line. Open with the short answer.
4. Run `python3 make_og.py && python3 build.py`, then upload `dist/`.

## Deploy to Hostinger

1. Hostinger hPanel → Websites → youssefjalloul.com → File Manager → `public_html`.
2. Upload everything inside `dist/` (not the folder itself).
3. Set `404.html` as the custom error page (hPanel → Advanced → Error pages) if you like the toaster joke.
4. Submit `https://youssefjalloul.com/sitemap.xml` in Google Search Console and Bing Webmaster Tools.
